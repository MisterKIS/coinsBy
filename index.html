🔐 Настройка API доступа

Для работы приложения требуется Google API ключ

Как получить ключ:

  1. Перейдите на Google Cloud Console
  2. Создайте проект и включите Google Sheets API
  3. В разделе "Credentials" создайте API Key
  4. Скопируйте ключ и вставьте выше

Ключ сохраняется только в вашем браузере и никуда не отправляется
